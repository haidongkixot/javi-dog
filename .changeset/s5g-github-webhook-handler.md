Checks in order: current secret (503 `not_configured`), `Content-Encoding` other than identity (415, before reading), signature header format (401, before reading), 1 MiB raw body (413), HMAC over the raw bytes with the current then previous secret (one 401 body for every cause), body-hash dedupe (202), UTF-8 JSON (202), shape classification (202), `installation*` changes (200 applied / 202 duplicate; `new_permissions_accepted` 202), per-event 3-day rule (202), `full_name` refresh, routing (202), JD-M01 validation (202, nothing stored), then insert, `touchSignal`, `touchVerifiedDelivery` and the body hash **last** (200). Store failures → 500 with nothing recorded. Injected `GithubWebhookDeps` (secrets, `GithubWebhookStore`, `insertEvents`, `touchSignal`, `readBody`, `now`, `log`); logs carry only the GUID (after verification, GUID-shaped), event, action and outcome. Also `readRawBody` / `WEBHOOK_MAX_BODY_BYTES` (bounded raw-byte reader), `githubWebhookNotConfigured`, `consoleGithubWebhookLog` and the `GithubEventRow` type (structurally a JD-M06 `NewEvent`).
