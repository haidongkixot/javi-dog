S5b review V1 (ADR-0016 Changes R1–R9).

JD-C02: `parseGeminiMetrics` points carry two in-memory-only, non-enumerable fields, `seriesId` (SHA-256 over all data-point attributes, the start time and the resolved session id) and `authType` (allowlisted `auth_type`). **Breaking:** `geminiUsageDelta(delta, model, at, authType)` takes the auth type, estimates cost only for `vertex-ai` and `gemini-api-key`, and always returns `estimated: false`. New exports: `GEMINI_AUTH_TYPES`, `GEMINI_PRICED_AUTH_TYPES`, type `GeminiAuthType`.

JD-C01: `usage on --platform gemini-cli` refuses telemetry redirections in the cwd's Gemini `.env` lookup chain, its `.gemini/settings.json` and the shell (`GEMINI_TELEMETRY_*`, `OTEL_EXPORTER_OTLP_*`; javi's own Claude Code values excepted), and says that Gemini usage is user-wide; each Gemini `SessionStart` hook re-checks and writes a local warning that `javi status` shows first; `usage off --platform gemini-cli` clears the warnings. Gemini usage: a series that started at or after the receiver counts from 0 (the G5 sibling rule still applies), groups are (session, model, auth type, end time), baselines are per series id, and the Gemini `usageEventId` hashes that group key (Claude Code unchanged). The Gemini user-settings backup never holds javi's block and a successful restore removes it. `uninstall --forget-token` keeps the token while the other platform's hooks for the project remain. `/v1/logs` and `/v1/traces` drain bodies of any size and answer `200 {}`. New exports: `findGeminiTelemetryOverrides`, `geminiEnvFileChain`, `dotenvKeys`, `isGeminiTelemetryEnvKey`, `telemetryEnvKeys`, `claudeHooksInstalled`, types `TelemetryOverride`, `GeminiBackup`, `GeminiTelemetryWarning`, `CumulativeBaseline`, `UsageGroupOptions`. Changed: `EnableGeminiResult.backup` is a `GeminiBackup`; `enableGeminiTelemetry` takes optional `ownEnv`; `DisableGeminiResult.backupRemoved`; `toUsageGroups` takes optional `{ receiverStartNs }`; `UsageGroup.authType`; `geminiHooksInstalled` takes an optional project ref; `HookDeps.env`/`cwd`; state gains Gemini telemetry warning methods.
