# JGR research — primary sources (2026-10-20)

- Method: a research agent queried primary sources (official docs, specifications, source repositories). Where the sandbox proxy blocked a site (opentelemetry.io, datatracker.ietf.org, rfc-editor.org, developers.openai.com, docs.stripe.com, docs.github.com, geminicli.com), the official GitHub source of the same document was used instead; this is noted per item.
- Orchestrator spot-check: the Claude Code monitoring page was re-fetched directly and items 1a–1d below were confirmed verbatim.
- Anything not verified is marked **NOT VERIFIED**.

## 1. Claude Code OpenTelemetry — <https://code.claude.com/docs/en/monitoring-usage>

- Enable with `CLAUDE_CODE_ENABLE_TELEMETRY=1`; exporters `OTEL_METRICS_EXPORTER` (`otlp`, `prometheus`, `console`, `none`), `OTEL_LOGS_EXPORTER` (`otlp`, `console`, `none`); `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_HEADERS` (e.g. `Authorization=Bearer …`); per-signal variants exist. Export intervals: metrics 60 000 ms, logs 5 000 ms by default.
- **1a.** `OTEL_EXPORTER_OTLP_PROTOCOL`: `grpc`, `http/json`, `http/protobuf` — **no default**; must be set. *(spot-checked)*
- **1b.** Metrics: `claude_code.session.count`, `claude_code.token.usage` (`type`: `input`, `output`, `cacheRead`, `cacheCreation`; plus `model`), `claude_code.cost.usage` (USD), `claude_code.lines_of_code.count`, `claude_code.pull_request.count`, `claude_code.commit.count`, `claude_code.code_edit_tool.decision`, `claude_code.active_time.total`. *(token types spot-checked)*
- Log events include `claude_code.user_prompt`, `claude_code.assistant_response`, `claude_code.tool_result` (`tool_name`, `success`, `duration_ms`), `claude_code.api_request` (`model`, `cost_usd`, `duration_ms`, `input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_creation_tokens`), `claude_code.api_error`, `claude_code.tool_decision` and more (list truncated in retrieval).
- **1c.** Prompt content is **redacted by default**; `OTEL_LOG_USER_PROMPTS=1` enables it. Tool details, assistant responses and raw API bodies are off by default. *(spot-checked)*
- **1d.** Standard attributes include `session.id`, `user.id` (anonymous), `organization.id`, `user.account_uuid` and **`user.email` — "always included when available"**. *(spot-checked)*

## 2. Claude Code hooks — <https://code.claude.com/docs/en/hooks>

- Events include `SessionStart`, `SessionEnd`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `Notification`, `SubagentStart`, `SubagentStop`, `TaskCreated`, `TaskCompleted`, `Stop`, `StopFailure`, `PreCompact`, `PostCompact` and others (33 in total at retrieval).
- Common input fields: `session_id`, `transcript_path`, `cwd`, `permission_mode`, `hook_event_name`; inside subagents `agent_id`, `agent_type`. Command hooks get JSON on stdin; HTTP hooks receive the same JSON as a POST body.
- Event specifics: `SessionStart.source`, `SessionEnd.reason`, `PreToolUse/PostToolUse.tool_name|tool_input|tool_response`, `Notification.notification_type` (`permission_prompt`, `idle_prompt`…), `Stop.last_assistant_message`, **`UserPromptSubmit.prompt` = raw prompt text**.

## 3. OpenTelemetry GenAI semantic conventions

- Moved to <https://github.com/open-telemetry/semantic-conventions-genai> (from semconv v1.42.0). Stability: **Development**. opentelemetry.io itself NOT VERIFIED (blocked).
- Attributes: `gen_ai.provider.name` (replaces deprecated `gen_ai.system`), `gen_ai.request.model`, `gen_ai.response.model`, `gen_ai.usage.input_tokens`, `gen_ai.usage.output_tokens`, `gen_ai.usage.cache_read.input_tokens`.
- Metrics: `gen_ai.client.token.usage` (histogram, `gen_ai.token.type` = input/output) existed up to v1.41; current main uses counters `gen_ai.client.inference.usage.{input_tokens, output_tokens, cache_read.input_tokens, cache_write.input_tokens, reasoning.output_tokens}`.

## 4. CloudEvents 1.0.2 — <https://github.com/cloudevents/spec/blob/v1.0.2/cloudevents/spec.md>

- Required: `id`, `source`, `specversion` (`"1.0"`), `type`; `source` + `id` unique per event (a re-send keeps the same `id`). Optional: `datacontenttype`, `dataschema`, `subject`, `time` (RFC 3339).
- Batch media type `application/cloudevents-batch+json` (JSON array).

## 7. Idempotency and backpressure

- `Idempotency-Key`: IETF draft `draft-ietf-httpapi-idempotency-key-header` (Standards Track draft, **not an RFC**; latest seen -07, likely expired — status NOT VERIFIED). Server semantics: missing key 400, key reuse with different payload 422, concurrent retry 409.
- `429 Too Many Requests`: RFC 6585 §4; MAY include `Retry-After`; MUST NOT be cached. `Retry-After`: RFC 9110 — HTTP-date or delay-seconds.

## 8. Request signing

- RFC 9421 *HTTP Message Signatures* (Feb 2024, Standards Track) — signatures/MACs over HTTP message components.
- Stripe (via official SDK source): HMAC-SHA256 over `"{timestamp}.{payload}"`, header `t=<ts>,v1=<sig>`, default tolerance 300 s.
- GitHub: `X-Hub-Signature-256: sha256=<hex HMAC of body>`, constant-time compare, **no timestamp** (no replay window).

## Decisions taken into JGR v0.1 (see spec)

| Finding | JGR change |
|---|---|
| Codex reasoning / Gemini "thought" tokens have no JGR counter | `usage_delta.reasoning_tokens` added |
| CloudEvents dedupes on `source` + `id` | Dedupe key is (`producer_id`, `event_id`) — spec §9 |
| Claude Code OTel sends `user.email` / `user.account_uuid` when available | OTLP receiver MUST drop identity attributes in L0 — spec §12 |
| Gemini exports prompts by default; Claude hooks receive raw prompts | Collectors MUST configure `logPrompts=false` and drop `prompt`, `tool_input`, `tool_response`, `last_assistant_message` — spec §12 |
| No default OTLP protocol in Claude Code; Codex supports `otlp-http` json/binary | Receiver accepts OTLP/HTTP `http/json` and `http/protobuf`; gRPC not on Vercel — spec §12 |
| GenAI semconv in Development and renamed metrics after v1.41 | Mappings pin semconv version per collector release |
| Idempotency-Key is an expired draft | JGR uses per-event `event_id`; batch `Idempotency-Key` optional and informative only |
| Stripe-style signing has a replay window; GitHub's does not | v0.2 signing: HMAC-SHA256 over `timestamp.body`, `t=,v1=` header, 300 s tolerance; RFC 9421 as upgrade path |
