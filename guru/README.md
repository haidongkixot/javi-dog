# Javi's Guru — reusable wisdom library

Generalized skills distilled from the Javi's Dog build by the `javi-guru` agent (`.claude/agents/javi-guru.md`) at project checkpoints. Each skill is written to be installable in **other** projects:

```bash
cp -R guru/skills/<skill-name> <other-project>/.claude/skills/
```

- [`CATALOG.md`](CATALOG.md) — all skills with version, confidence and origin.
- [`WISDOM_LOG.md`](WISDOM_LOG.md) — checkpoint history: lessons (verified vs. hypothesis), skills created/updated, proposals.

Quality bar: verified finding ≠ hypothesis · no secrets · no invented root causes · owner review before shared-policy changes. Skills with medium+ confidence may be proposed to [haidongkixot/orcasus](https://github.com/haidongkixot/orcasus) at checkpoints G2 and G4.
